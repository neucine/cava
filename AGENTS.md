# Cava agent notes

- Record new Cyna language, compiler, runtime, standard-library, and tooling
  gaps only in the sibling Cyna repository's `docs/LANGUAGE_GAPS.md`. Include
  the Cava site, compiler revision, minimal reproduction, and workaround.
- Do not create or append to a Cava-local Cyna gap log. `docs/gap-log.md` is
  historical evidence. Keep Cava-specific JVM work in the porting plan or
  ordinary project tasks.
- Verify a Cyna fix with the compiler used by Cava before removing a workaround.
